# Getting Started

## Installation

```bash
pip install spectralin
```

## Scan a Project

```bash
spectralin scan ./src
```

## JSON Output

```bash
spectralin scan ./src --format json
```

## Filter by Severity

```bash
spectralin scan ./src --severity error
```

## Integration

Spectralin integrates with pre-commit hooks, CI pipelines, and editor plugins.
